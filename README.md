# Paisa Desk – Merchant Onboarding & Transaction Dashboard

React 18 + TypeScript + Vite. No backend; all data is synthetic, generated by a seeded RNG (`src/data.ts`) and served through a simulated async API (`fakeFetch`).

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # status-transition + CSV unit tests (Vitest)
npm run build
```

## Features
- **Dashboard**: four summary cards and an interactive SVG trend chart (hover or ←/→ keys, volume/count toggle).
- **Merchants**: search, status filter, sortable columns, pagination, detail panel (contact, document checklist, timeline).
- **Review actions**: Approve / Reject / Request information through a native `<dialog>`; reject and request require a note (min 10 chars). Timeline updates instantly with a toast.
- **Transactions**: search, status and date-range filters, sortable, detail panel, CSV export of filtered rows.
- **Roles**: Admin / Merchant toggle in the header. Merchant is read-only.
- **States**: skeleton loading, empty, error + Retry (use the "Simulate API error" checkbox, then Retry).
- **Bonus**: filters, tab and role persist in localStorage; light/dark follows system; reduced-motion respected.

## Design decisions
- **Transitions live in one table** (`TRANSITIONS` in `src/lib.ts`): Pending → Under Review (request info) or Rejected; Under Review → Approved / Rejected / stays (request more info); Approved and Rejected are final. The UI disables invalid buttons and the handler re-checks, so invalid moves cannot occur even if the UI is bypassed.
- **No chart library**: a small SVG chart keeps the bundle light and is keyboard accessible.
- **Native `<dialog>`** for focus trapping and Esc handling; labelled inputs, `aria-sort`, `aria-live` feedback, visible focus, skip link.
- State is kept in `App` and passed down; feature screens own their filter state.

## Assumptions / not done
- Approving auto-marks all documents as received (mock behaviour).
- Merchant role is a UI demo, not real auth. No e2e tests; no hosted link yet (deploy with Vercel/Netlify: build command `npm run build`, output `dist`).
